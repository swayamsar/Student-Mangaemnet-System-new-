# Student-Management-System

## Description
A Java-based Student Management System developed to manage student records efficiently through a graphical user interface (GUI). The system allows users to add, update, delete, and view student details in an organized manner.

## Features
- Add new student records
- Update existing student information
- Delete student records
- View student details
- User-friendly GUI interface
- File handling/database support for data storage

## Technologies Used
- Java
- Swing (GUI)
- OOP Concepts
- File Handling

## How to Run
1. Compile the Java file
2. Run `StudentManagementGUI.java`
3. Use GUI buttons to manage students
