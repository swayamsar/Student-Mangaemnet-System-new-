# Student-Management-System

A Java-based Student Management System designed to manage student records, academic details, and administrative operations efficiently.

## Features
- Add, update, and delete student records
- Store academic information
- User-friendly interface
- Database connectivity support

## Technologies Used
- Java
- MySQL
- JDBC
- OOP Concepts
